# 🥮 Web Chúc Tết Trung Thu 2026 - Mai Thảo (Thảo Chim To) ✨

Trang web chúc mừng Tết Trung Thu độc bản, hài hước và giàu cảm xúc dành tặng bạn thân Mai Thảo.

## 🌟 Tính Năng Nổi Bật
- **Màn chào mở đầu & Nhạc nền**: Bật nhạc du dương và mở ra thế giới trăng rằm.
- **Bầu trời đêm & Trăng rằm 3D**: Hiệu ứng sao băng, đom đóm, chạm màn hình bung tỏa sao sáng.
- **Bức mật thư hoàng gia**: Lời chúc 5 điều đại cát lầy lội chan chứa tình bạn chân thành.
- **Gõ Mõ Giải Nghiệp & Tích Đức**: Âm thanh gõ mõ chân thực, rơi buff tài lộc, tình duyên.
- **Album kỷ niệm Polaroid**: Dây đèn Fairy lights đung đưa với 5 khoảnh khắc đáng nhớ của Thảo.
- **Cắt bánh Trung Thu - Rút quẻ**: Hiệu ứng dao cắt bánh và mở quẻ may mắn bất ngờ.
- **Thả đèn trời cầu nguyện**: Chiếc đèn lồng mang dòng điều ước bay vút lên bầu trời sao.
- **Bản cam kết tình bạn**: Nút từ chối tự động chạy trốn khắp màn hình khi chạm vào!
- **Đĩa than mini**: Xoay tròn theo nhạc kèm sóng âm thanh chuyển động.

## 🚀 Cách Trải Nghiệm
1. **Mở trực tiếp**: Nhấp đúp vào file `index.html` trên bất kỳ trình duyệt nào (Chrome, Safari, Edge...).
2. **Chạy server nội bộ** (nếu muốn):
```bash
node server.js
```
Truy cập: `http://localhost:3000`
